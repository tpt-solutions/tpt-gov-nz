# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion
focused on the work. Harassment, personal attacks, and publishing other people's
private information are not acceptable in issues, discussions or any other project
space.

Because this project accepts contributions as issues only (see
[CONTRIBUTING.md](./CONTRIBUTING.md)), raise conduct concerns with the maintainers
through a GitHub issue. If the issue itself contains sensitive content, report it
privately through GitHub's reporting tools instead. Maintainers will respond to
reports and may hide content, lock threads, or restrict participation as set out
in the Covenant's enforcement guidelines.
