# Architecture decision records

Decisions that shape the platform are recorded here, one file per decision, numbered
in order. Each record has a status (Proposed, Accepted, Superseded) and states its
context, the decision, and the consequences. To change a decision, add a new record
that supersedes the old one rather than editing the accepted text.
